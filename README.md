# 🥛 Симулятор управления запасами скоропортящихся товаров

Разработка имитационной модели для анализа и оптимизации управления запасами товаров с ограниченным сроком годности.

## О проекте

Программа позволяет симулировать работу склада с товарами, у которых есть срок годности. Поддерживает:

- Два типа товаров: строгий срок (молоко) и постепенная порча (овощи/фрукты)
- Три модели порчи: линейная, степенная, логистическая
- Четыре стратегии поставок: (R,S), (R,Q), (s,S), (s,Q)
- Два закона спроса: равномерный, нормальный (с эмпирическими сигмами)
- Поведение покупателей: FIFO / LIFO с настраиваемым процентом
- Импорт реальных данных из Excel
- Усреднение результатов по N симуляциям (метод Монте-Карло)
- Сохранение экспериментов в базу данных
- Выгрузка отчётов в многостраничный Excel

## Быстрый старт

### 1. Клонирование репозитория

git clone https://github.com/mpaskonny/perishable-api.git
cd perishable-api

### 2. Создание виртуального окружения

python -m venv venv

Активация:
- Windows: venv\Scripts\activate
- Mac/Linux: source venv/bin/activate

### 3. Установка зависимостей

pip install -r requirements.txt

### 4. Запуск приложения

Запустить бэкенд (FastAPI):

uvicorn main:app

С автоматической перезагрузкой при изменении кода:

uvicorn main:app --reload

API будет доступно по адресу: http://127.0.0.1:8000

Документация Swagger: http://127.0.0.1:8000/docs

Запустить фронтенд (Streamlit):

streamlit run app.py

Веб-интерфейс будет доступен по адресу: http://localhost:8501

## Пример использования

1. Добавьте товар вкладка База данных кнопка Добавить товар

3. Запустите расчёт кнопка Запустить симуляцию

## Экспорт результатов в Excel

При выгрузке эксперимента формируется многостраничный Excel-отчёт:

- Метрики: ключевые показатели эффективности
- 1. Общие настройки: параметры товара, спроса, порчи
- 2. Стратегия поставок: выбранная стратегия и её параметры
- 3. Доставка: стоимость доставки
- Детально по дням: полная история с русскими названиями
